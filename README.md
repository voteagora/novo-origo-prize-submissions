# Novo Origo Prize — Submissions

**Repository:** [voteagora/novo-origo-prize-submissions](https://github.com/voteagora/novo-origo-prize-submissions)

Submissions are licensed under **CC BY-SA 4.0** as described in the [official contest rules](https://novo-origo.agora.xyz/rules).

## How submissions get here

When someone submits through [the contest site](https://novo-origo.agora.xyz/submissions/new), automation will:

1. Create a branch named `submission/<wallet-address>/<title-slug>`
2. Add `submissions/<wallet-address>/<title-slug>/README.md` with the submission title, author wallet, and a link to the full entry on [novo-origo.agora.xyz](https://novo-origo.agora.xyz/)
3. Open a pull request targeting `main`

## Pull requests and qualification

A merged PR means the submission is qualified. A closed PR without merge means it is not qualified and has been removed from the contest.
